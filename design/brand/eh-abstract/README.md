# EH / Abstract · 第二轮设计

根据“弱化可直接辨认的 E、H，并使用更活泼、多样的配色”的反馈，重新设计两个抽象几何方向。

- **01 / 旋扣**：三段回折的带状结构以 120° 旋转排列，形成六边形轮廓和开放的中心负空间。主配色为珊瑚橙、芒果黄、紫色；另一组配色为青柠、薄荷绿、蓝紫。
- **02 / 交叠**：两条连续折带以半周旋转组合，使用斜向穿插暗示空间。主配色为玫红与紫色；另一组为橘色与桃红。

E 的分段、H 的连接关系仅作为构思起点，不以直接辨认字母为目标。主形依靠转折与负空间成立，单色版可直接使用。

## 交付

`eh-design-board.png` / `.svg` 为完整对照板，`eh-size-check.png` / `.svg` 为实际尺寸预览。

两个方向均提供下列 SVG 和 1024 × 1024 PNG：

| 后缀 | 内容 |
| --- | --- |
| `-mark` | 彩色主标志，透明背景 |
| `-mono` | 单色主标志，透明背景，合并路径消除接缝 |
| `-icon` | 白色圆角图标 |
| `-dark` | 深色圆角图标 |
| `-alternate` | 另一组配色的圆角图标 |

标志均为直接绘制的矢量路径，不含字体、位图、滤镜或渐变。色块间的微量同色重叠用于避免渲染细缝；留白为透明负空间，深色底下仍保持穿透。

`build.cjs` 是几何与色值的共同来源。需要 Node.js 及可解析到的 `sharp` 包，在仓库根目录运行 `node design/brand/eh-abstract/build.cjs` 可重新生成。展示板文字使用 Microsoft YaHei。

本轮资源单独保存，旧的折面方案留作历史对照；应用 launcher 资源尚未替换。
