# EH / 交叠 · 填充凹面版

在已选定的「02 交叠」轻拟物方案上，把上下两处镂空填为浅粉至浅紫的连续材质面。主体成为完整的六边形徽记，折带以浅浮雕形式压在同一底面上。

## 本轮调整

- 增加与主体外轮廓相同的圆角六边形实体底面，原镂空处不再透出图标底板。
- 凹面采用低饱和粉紫渐变，保持与玫红、紫色折带的材质统一。
- 折带侧边由原稿的 4/512 降为 2/512，接触阴影的偏移与模糊也同步降低。
- 外投影改为完整徽记的投影，缩短距离，减少悬浮感。
- 保留折带的几何结构、圆角、渐变和柔和高光。

所有材质由可编辑矢量路径、渐变和 SVG 滤镜组成，无嵌入位图。PNG 已完成阴影渲染。原镂空版本保留在相邻的 `eh-link-soft` 目录中供对照。

需要 Node.js 与可解析到的 `sharp` 包，运行 `node design/brand/eh-link-inlay/build.cjs` 可重新生成。未替换应用资源或进行设备安装验证。
