# EH / 叠层 · 右下小窗

按“粉色叠在紫色上面，右下角留一个小窗”调整图标。粉色成为完整的上层面，紫色成为连续的底层，从下缘与右下角小窗露出。

## 形体

- 保留六边形外轮廓、粉紫渐变、适度圆角与轻拟物材质。
- 粉色上层覆盖底层的大部分面积，接触阴影统一向下投在紫色上。
- 小窗沿 30° 斜线开在右下方，带圆角；穿过粉色，露出真正的紫色底层。
- 窗口与外侧的紫色底面使用同一条连续渐变，维持空间关系。主体整体有实体承托，窗口不会透出图标底板。
- 单色版将小窗转译为留白，以保持识别。

## 交付

`eh-link-icon` 为浅色图标，`eh-link-dark` 为深色图标，`eh-link-app-square` 为不预裁圆角的方形图标，`eh-link-mark` 为透明外背景的主体，`eh-link-mono` 为单色版；均有 SVG 和 1024 × 1024 PNG。

另附 48、64、96、192、512 px 图标、`eh-refinement-board` 展示板，以及 `eh-size-check` 实际尺寸对照。

由矢量路径、渐变和 SVG 阴影滤镜构成，无嵌入位图。需要 Node.js 和可解析到的 `sharp` 包，运行 `node design/brand/eh-link-overlay/build.cjs` 可重新生成。

此前版本保留在相邻目录，未替换应用资源。
