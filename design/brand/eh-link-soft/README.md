# EH / 交叠 · 轻拟物细化

在用户选定的第二轮 02「交叠」基础上细化，保留双折带组合与玫红、紫色配色。

- 用二次贝塞尔曲线为原始多边形添加适度圆角，保留六边形的辨识轮廓。
- 主体由左上向右下逐步加深，使用浅粉至玫红、浅紫至深紫的连续渐变。
- 在前景下方增加 4/512 的侧边厚度；柔和投影和交接处的局部阴影表现浅浮雕与穿插关系。
- 加入低强度边缘高光；底板采用浅薰衣草白或深紫灰渐变。

## 文件

| 文件 | 内容 |
| --- | --- |
| `eh-refinement-board.png` / `.svg` | 浅色主版本、深色版本及小尺寸对照 |
| `eh-link-icon.png` / `.svg` | 浅色圆角预览，PNG 为 1024 × 1024 |
| `eh-link-dark.png` / `.svg` | 深色圆角预览，PNG 为 1024 × 1024 |
| `eh-link-app-square.png` / `.svg` | 无预裁圆角的完整方形底板，PNG 为 1024 × 1024，可供平台施加图标遮罩 |

| `eh-link-mono.png` / `.svg` | 透明背景单色版，共同的圆角几何 |
| `eh-link-icon-{48,64,96,192,512}.png` | 多尺寸浅色图标 |
| `eh-size-check.png` / `.svg` | 24、32、48、64、96、128 px 的实际尺寸检查 |

标志由可编辑矢量路径、渐变和 SVG 滤镜组成，不含嵌入位图。SVG 阴影使用滤镜；PNG 已将其渲染完成。透明留白可透出底板。

所有资源由 `build.cjs` 同源生成。需要 Node.js 及可解析到的 `sharp` 包：

```powershell
node design/brand/eh-link-soft/build.cjs
```

此目录为设计交付，尚未替换应用资源或进行设备安装验证。
