# EH / 同色系杏橙 · 加大矩形窗

将圆孔恢复为原来的斜向圆角矩形，并加大；底层改为与浅杏橙上层同色系的深杏橙渐变。

- 窗口顶点为 (284, 284)、(368, 235.5)、(368, 291.5)、(284, 340)，沿原有约 30° 的斜线方向，保留适度圆角。
- 相较上一版矩形窗的 58 × 42 局部尺寸，本版为 84 × 56，名义面积约为 1.93 倍。
- 保留贯穿两层的镂空，独立主体中的窗心完全透明；图标版透出浅色或深色底板。
- 上层沿用浅杏橙，底层使用较深的橙色，通过明度与接触阴影区分叠层。
- 延续柔和渐变、轻薄侧边与低强度孔缘明暗。

`eh-link-icon` / `eh-link-dark` 为浅色、深色图标；`eh-link-app-square` 为完整方形底板；`eh-link-mark` 为透明背景主体；`eh-link-mono` 为单色版。均包含 SVG 与 1024 × 1024 PNG。

另附多尺寸 PNG、`eh-refinement-board` 展示板和 `eh-size-check` 尺寸检查。SVG 为可编辑路径、渐变和滤镜，无嵌入位图。

需要 Node.js 和可解析到的 `sharp` 包，运行 `node design/brand/eh-link-tonal/build.cjs` 可重新生成。旧版本留在相邻目录，应用资源未替换。
